# yarp-gateway

YARP (Yet Another Reverse Proxy) — the execution layer for traffic-shifting recovery actions
(Doc1 §1, §5). The Decision Engine patches cluster destination weights through this service's
internal admin API to drain traffic from a failing pod without killing it.

Not yet scaffolded. See `CLAUDE.md` in this folder and `docs/Doc3_Execution_Guide.md` Phase 5 for
the init command (`dotnet new web`) and files to write.
